# 주제 클러스터

기계가 읽는 데이터는 `_candidates.csv`(후보·점수)와 `_pipeline.csv`(글별 상태)다. 이 파일은 사람이 읽는 설명이다. 클러스터에 새 글을 넣을 때는 두 CSV와 이 표를 같이 고친다.

## 1. 연말정산-부양가족 (2026-10-24 시작)

**허브: 12편** `연말정산 부양가족 기준, 소득 100만원 초과면 공제가 통째로 빠집니다` (logNo 224436054552). 요청서 1번 주제(소득금액 100만원)는 12편이 이미 다뤄 `UPDATE_EXISTING`으로 분류됐다(`pipeline.py score`가 자동 판정). 새 글 9편은 허브가 못 답하는 **부모님 소득 종류별 롱테일**이다.

규칙: 클러스터 글은 같은 클러스터의 **발행된 글** 2~3개로 링크한다(`작성 메모`의 `- 내부 링크 대상: 12 | 25`). 아직 안 쓴 글은 링크하지 않고, 발행 뒤 `pipeline.py links NN`이 기존 글 수정 후보를 낸다. 수정·재발행은 사용자 승인 후.

### 발행 순서와 글별 계획

- 순서는 시즌(11월 간소화 오픈 전) 안에 조건이 단순한 것부터 넣는다. 허브 갱신은 3번 발행 뒤(링크가 2개 이상 생긴 시점).
- `FACT_CHECK_REQUIRED`로 시작하는 확인 항목: 직계존속 연령 요건, 소득금액 100만원·총급여 500만원 기준 및 올해 귀속 개정 여부, 국민연금·기초연금의 소득 처리, 사업·금융소득 계산 방식, 형제 중복공제 시 가산세 여부, 경정청구 기한. 확인 못 한 숫자는 쓰지 않는다.
- bg-02·bg-08은 AI 브리핑이 없는 질의다. 인용 자리가 없으니 인용을 기대하지 말고 검색 순위와 방문으로만 평가한다.
- `official`·`diff` 점수는 사용자 검토 전 임시 입력이다(전부 1). 고치면 `pipeline.py score`를 다시 돌린다.

### 7일·30일 점검 기준 (글 단위, `pipeline.py perf`)

| 시점 | 기준 | 미충족 시 |
|---|---|---|
| 24시간 | 발행 이상 없음(색인·태그·서식) — 지표는 기록만 | 없음 |
| 7일 | 검색 유입 1건 이상 → B 이상. 목표 키워드가 `_ranks.csv`에서 30위 안인지 | 제목·도입에 질의의 단어가 있는지 재확인 |
| 30일 | 검색 유입 0이면 UPDATE_REQUIRED 후보(삭제 금지). A·B면 하위 질문 2개 후보 등록 | 제목·도입·검색 의도 재검토 |
| 클러스터 | 4편 발행 뒤 `_ranks.csv`·`_geo.csv` 첫 점검. 30위 안 글이 0편이면 클러스터를 늘리지 않는다 | 규모 확대 중단, 원인 분석 |

글 단위 등급(A~E)은 `manager.py`의 방문자 판정(10편 15명 / 20편 50명)과 별개이며, 그 기준을 바꾸지 않는다.
