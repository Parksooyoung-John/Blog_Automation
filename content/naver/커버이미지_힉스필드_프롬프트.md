# 네이버 모바일 커버 — Higgsfield 프롬프트

블로그: 머니브리핑 | 지원금·세금 정리
용도: 관리 → 꾸미기 설정 → 모바일 앱 커버 설정

## 규칙 두 가지

1. **한글 텍스트를 AI에게 맡기지 않는다.** 배경만 생성하고 글자는 나중에 얹는다.
2. **본문 이미지에는 계속 AI를 쓰지 않는다.** 커버는 브랜딩 요소라 예외다.

## 생성 설정

- 비율 3:4로 생성 후 1080 x 1300으로 크롭
- 커버 스타일에 따라 상하가 잘리므로 중요한 요소는 가운데에
- 텍스트 얹을 여백을 반드시 비워둘 것

# 프로필 이미지 — Higgsfield 프롬프트

용도: 관리 → 기본 설정 → 기본 정보 관리 → 프로필 이미지

## 제약 — 아주 작게 보인다

검색 결과의 블로그명 옆, 모바일 프로필에서 **40~100px**로 줄어든다. 여기서 결정되는 것:

- 심볼은 **하나만**. 두 개 이상이면 뭉개진다
- 색은 **2색 이하**
- **얇은 선 금지.** 1~2px 선은 축소 시 사라진다
- **한글·영문 금지.** 읽히지 않고, AI가 글자를 제대로 못 만든다
- 원형으로 잘릴 수 있으니 **가장자리 15%는 비워둔다**

## 생성 설정

- 비율 1:1, 1000 x 1000 이상
- 배경은 흰색 또는 단색

## 고를 때

생성된 이미지를 **40px로 줄여서 본다.** 무슨 모양인지 알아볼 수 없으면 탈락이다.
커버와 같은 계열을 골라야 블로그 전체가 하나로 보인다.
