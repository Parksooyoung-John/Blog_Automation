# PRD — 티스토리 → Threads 승인형 자동 게시

## 목표

머니브리핑 블로그의 핵심 내용을 Threads 문법에 맞게 재구성하고, 사람이 승인한 콘텐츠만
KST 08:30·18:30에 게시해 수작업을 줄이면서 금융 콘텐츠의 정확성을 보존한다.

## 사용자 흐름

1. 시간별 동기화가 최신 블로그 글을 감지한다.
2. Writer와 Reviewer가 단일 글 또는 3~5개 연속 스레드를 만든다.
3. Harness가 별도 Notion DB에 `초안`으로 저장한다.
4. 운영자가 문구·예약시각을 수정하고 상태를 `승인`으로 바꾼다.
5. Publisher가 다음 빈 슬롯을 배정하고 도래한 항목 최대 1건을 게시한다.
6. 게시 ID·시각·오류를 같은 Notion 페이지에 기록한다.

## 기능 요구사항

- 최초 명시적 백필은 최신 10건, 정기 동기화는 최근 48시간 신규 글만 대상으로 한다.
- canonical 숫자 URL과 Tistory ID로 중복을 방지한다.
- 게시 완료 후 원문 수정은 해시만 갱신한다.
- 미게시 원문 수정은 초안을 재생성하고 승인을 초기화한다.
- 모든 게시문은 480자 안전 한도를 지키며 원문 링크 규칙을 만족해야 한다.
- 부분 게시 실패는 저장된 Threads ID 다음 답글부터 재개한다.

## 성공 기준

- 미승인 게시 0건, 동일 원문 중복 게시 0건
- 예약시각 15분 이내 게시
- 부분 실패 재실행 시 기존 게시물 중복 생성 0건
- 비밀값과 게시문 전문을 Actions 로그에 출력하지 않음

## v1 제외

X·Instagram, 이미지/영상, 자동 답글, 게시 삭제, 인사이트, 다중 계정 OAuth,
자동 토큰 갱신은 포함하지 않는다.
