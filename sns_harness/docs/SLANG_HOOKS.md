# 밈·유행어를 Threads 훅으로 쓰는 절차

블로그 본문·제목에는 쓰지 않는다 (금융 주제 일관성, C-Rank). Threads(`money.ybrief`) 훅 전용이다.
자동 수집 소스는 두지 않는다 — 나무위키는 CC BY-NC-SA에 봇 차단이 있고, 네이버·네이트 실시간 검색어는 종료됐다.
후보는 사람이 던지거나 Claude WebSearch로 보조하고, **검색 실체가 확인된 것만** 쓴다.

## 검증 (이미 있는 명령 재사용)

```bash
python -m sns_harness research-topics --keyword "후보1" --keyword "후보2" --days 30
```

출력의 `series`(일별 ratio)와 `trend_direction`을 본다.

| 결과 | 판정 |
|---|---|
| `series`가 대부분 0 | 탈락 — 검색 실체가 없다 |
| `trend_direction`이 하락 | 탈락 — 이미 식은 유행이다 |
| 상승 또는 유지, 값이 0이 아님 | 통과 후보 |

`trend_score`는 **한 요청 안에서만** 정규화(최댓값 기준 100)된다. 서로 다른 요청의 점수를 비교하지 말 것.
여러 후보를 비교하려면 한 요청(최대 5개)에 같이 넣는다. 블로그 쪽의 앵커 방식은 루트 `trend_scan.py` 참고.

## 훅으로 쓸 때

- 금융 내용과 어울리는 경우에만 쓴다. 억지로 붙이면 `compliance_reviewer`의 과장·오해 기준에 걸리기 쉽다.
- 밈의 출처·원래 맥락을 확인하지 못했으면 쓰지 않는다 (차별·비하 표현이 섞인 신조어가 많다).
- 통과했다고 글감이 되는 것이 아니다 — 승인 큐(Notion)를 거치는 기존 흐름은 그대로다.
