# Threads 게시물별 조회수 분석 (2026-10-19 기준)

재현: `python -m sns_harness metrics report --days 60` (Notion 큐의 측정값을 읽기만 한다. 24h 우선, 없으면 72h·7d).
측정 게시물은 9/21~9/28 14건, 9/29~10/18 12건이다. 규칙을 하드 제한으로 바꾸려면 30건 이상 필요하다(`enough_for_rules`).

| 관찰 | 근거 | 한계 |
|---|---|---|
| 24h 값이 7d 값의 99% 이상 | 4,703→4,713, 932→938, 736→740 | 판정은 24h로 한다. 7일 대기 불필요 |
| 중앙값 개선 없음 | 약 760(9/21~28) → 약 640(9/29~10/18) | 상위 2건(4,713·3,182)이 평균을 끌어올린다. 평균은 쓰지 않는다 |
| 상위권 첫 게시물이 짧다 | 33자 4,713 / 29자 3,182 / 24자 938 | 같은 길이인데 175·40도 있다. 길이만으론 설명 안 됨 |
| 하위권은 90자 넘는 평서형 시작 | 112자 9, 156자 17, 223자 193, 92자 543 | n이 작다 |
| 주제 영향이 크다 | 건보료·실업급여 높음, 연말정산 부양가족 40·의료비 193 | 시즌 키워드 약세 가능성. 훅 유형(질문·실수·숫자)은 구분되지 않음 |
| 도달 낮고 반응 높은 글 | 부양가족: 조회 40, 좋아요 11, 리포스트 9 | 도달 규칙과 저장·공유 규칙을 따로 봐야 함 |
| 이미지 효과 미측정 | 이미지 붙은 게시 10/18 1건, 미측정 | 카드뉴스 도입 후 A/B로 처음 측정 |

링크 유무(3건 vs 9건)와 슬롯은 표본이 작아 결론 내지 않았다.

## 반영한 규칙 (`prompts/threads_writer.md`)
- 훅 40자 안팎·한 문장·주제 명사 먼저, 평서형 설명으로 시작하지 않기, 시즌 주제는 금액·조건을 앞에, 카드뉴스가 있으면 카드 내용을 반복하지 않기.
- 검증기의 `hook_text` 15~80자는 그대로 둔다(데이터가 하드 제한을 정당화하지 못함).
- 판정 창을 24h 우선으로 바꿨다(`operations/manager.py`).
- 재검토: 측정 30건 이상.

## 노션 가이드 KPI와 Threads API로 얻을 수 있는 범위 (2026-10-21)

공식 문서(Threads Insights API) 기준이다. 게시물 단위는 `views, likes, replies, reposts, quotes, shares`뿐이고,
**프로필 방문·팔로우·링크 클릭은 계정 단위**다(`views`=프로필 조회 일별, `clicks`=공유한 URL별, `followers_count`=현재 총합, 이력 없음).

| 가이드 KPI | `metrics report`에서 | 비고 |
|---|---|---|
| 참여율 | 행별 `engagement`, 훅별 `by_hook.median_engagement` | (좋아요+답글+리포스트+인용·공유) ÷ 조회 |
| 링크 클릭 | 행별 `link_clicks` (링크 쓴 글만) | 최근 30일 안에 공유한 URL별 클릭. 클릭률의 분모(프로필 방문)는 게시물별로 없다 |
| 프로필 방문율 | `summary.account.profile_view_rate` | 계정 프로필 조회 ÷ 게시물 조회 합. 게시물별 귀속은 불가 |
| 1,000조회당 팔로우 | 미구현 | `followers_count`가 현재값뿐이라 일별 스냅샷을 쌓아야 증가분이 나온다 |
