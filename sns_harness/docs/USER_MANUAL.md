# MoneyBrief SNS Harness 운영자 매뉴얼

## 초안 확인과 승인

Notion SNS 게시 큐에서 `상태`, `콘텐츠유형`, `게시슬롯`, `첫게시물`, `답글1~4`, `오류`를 확인합니다.
자동 생성 글은 항상 `초안`으로 저장됩니다. 문장을 수정한 뒤 내용이 맞을 때만 `상태`를 `승인`으로 바꾸세요.

승인 전에는 예약시각을 확정하지 않습니다. 승인했는데 예약이 안 잡히면 상태가 정확히 `승인`인지,
예약시각이 과거인지, 같은 유형의 당일 슬롯이 이미 사용 중인지 확인한 뒤 게시 workflow를 수동 실행합니다.

## 게시 성공 확인

성공한 항목은 다음 세 가지가 모두 있어야 합니다.

- `상태 = 게시완료`
- `ThreadsIDs`에 실제 ID
- `게시시각`과 게시물 URL

상태만 게시완료이고 ID가 비어 있으면 성공으로 보지 않습니다. 실패 항목은 예약시각이 제거되고
`오류` 상태로 격리됩니다.

## 오류 복구

```powershell
.\.venv\Scripts\python.exe -m sns_harness sync --retry-errors
```

복구에 성공하면 새 `초안`이 만들어집니다. 모바일 Notion에서 다시 확인하고 `승인`해야 재예약됩니다.

## 검색 추세 확인

네이버 데이터랩은 현재 사용하지 않습니다. 신규 API 키 발급 제약 때문에 운영 Manager는
Threads 공식 인사이트와 최근 게시 성과를 바탕으로 판단하며, 검색 추세는 `미측정`으로 남깁니다.

## 성과 기록 원칙

Threads API에서 확인된 값만 자동 기록합니다. 제공되지 않는 값은 `미측정`으로 둡니다.
네이버 블로그 내부 조회수는 `블로그조회수`에 직접 입력합니다. 실험에서는 주제·Hook·시간·링크 사용 여부 중
한 번에 하나만 바꾸면 결과를 비교하기 쉽습니다.

## 안전 규칙

- 승인 전 게시 금지
- 네이버에는 읽기 요청만 사용
- 원문에 없는 금액·기한·수익률 추가 금지
- API 키와 액세스 토큰을 로그·Notion·Git에 기록하지 않기
